So erstellst du ein PNG-Bild:

  1. Öffne diese Datei im Browser
  2. Mache einen Screenshot des Bildes oben (genau 1200x630px)
  3. Oder verwende Browser DevTools:
    • F12 > Console eingeben: const canvas = document.createElement('canvas'); canvas.width=1200; canvas.height=630;
    • Screenshot-Tool verwenden
  4. Speichere das Bild als /public/og-image.png

Oder verwende die dynamische API:

Die Datei /src/app/api/og/route.tsx generiert automatisch OG-Images.

Verwendung: https://jobnachbar.com/api/og?title=Dein%20Titel&subtitle=Dein%20Untertitel

Oder verwende das SVG:

Das statische SVG unter /public/og-image.svg kann direkt verwendet werden.
